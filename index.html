一年半，不只是“上了很多课”

更重要的是，孩子已经走过了一条完整的能力进阶路线。

兴趣被点亮

从认识角色、指令和程序，到愿意主动探索“还能怎么做”。

能力走向综合

把不同知识组合起来，分析任务、排查问题、完成更复杂的作品。

孩子积累的，不只是一件件作品，更是一套面对问题时可以反复使用的思考方法。

07

Python 不是英语课

家长和孩子最常见的担心是：“英语基础不够，会不会学不会？”

不需要大量英语基础。

Python 里的英文，大多是数量有限、会反复使用的固定指令。孩子需要理解它们在程序里的作用，而不是背长单词、学语法或参加英语考试。

print = 输出if = 如果for = 重复执行list = 列表
就像孩子熟悉游戏里的“技能名称”：在一次次使用中，自然记住什么时候用、怎么用。老师也会从读代码、模仿代码，逐步过渡到独立书写。
08

Python 第一学期，会学什么？

从直观、有反馈的项目开始，让孩子在“代码真的能创造东西”中建立信心。

代码基础与规范

认识运行方式，学会正确输入、阅读和修改代码。

运算与变量

让程序能够计算、记录数据，并根据数据产生变化。

判断与循环

让程序根据条件作出选择，自动完成重复任务。

turtle 创意绘图

用代码控制“小海龟”画图，在即时反馈中理解坐标与循环。

列表与综合项目

管理多组数据，把知识组合起来完成更完整的作品。

09

为什么现在进入 Python 最合适？

① 思维基础已经建立

孩子理解了变量、循环、判断等核心概念，现在可以把这些逻辑迁移到代码中。

② 从“低门槛兴趣”走向“真实代码能力”

图形化保护了早期兴趣，Python 则进一步训练准确表达、阅读代码和独立调试。

③ 难度衔接更自然

现在升级，旧知识还熟悉，老师可以用熟悉的项目作桥梁，降低畏难感。

过早进入代码，容易因输入与语法受挫；一直停留在图形化，又会错过能力升级。完成 S3 后衔接 Python，正是承上启下的好时机。
